2 This project

The structure that I want is a private repository (If you are reading this is because you colaborate or I decided that the project is mature enough to make it public) that will have all the scripts needed to config the new distro.

Ansible and playbooks are also options to take into account but, because the distro is configured for using as “regular-manager/coder-user” I don’t need any specific “server-side” conditions. So I decided more the literate-programming approach to fullfil my customization requirements.

Obviously what is inside is this main ORG file, that is a literate document; so once you installed Emacs and Spacemacs you will be able to execute the configurations as you wish.

Summarizing, the step-0 is to have git (if you are reading this document sequentialy you may have needed before). 

git version

If Ctr+C Ctr+C does not works showing you the following message: “Evaluation of this sh code block is disabled” then you may have a problem on configuration here is a trick:

  • https://emacs.stackexchange.com/questions/233/how-to-proceed-on-package-el-signature-check-failure

This configuration project also is assuming that the target linux installation uses ’apt’ package manager. Because I also have som systema on Fedora that uses ’dnf’ package manager you may also find some code to install most used packages.

This kind of errors may happen if you play too much with Emacs or Org package, I came up with this problem in Spacemacs. But in DOOM Emacs worked as expected from the first time. Anyway, if you have further problems let me know!

4 Terminal

4.1 Powerline

Powerline is a very usefull aplication when you use git, I recommend to install it. More info at: 

sudo apt-get install fonts-powerline powerline

For DNF package manager 

sudo dnf install powerline

After installation you should include into your .bashrc the initialization of the powerline, for doing this first check your installation path 

whereis powerline

You should have a script to be included on your .bashrc: 

ls -l /usr/share/powerline/bash/powerline.sh

If th above is working then you can addit executing the following code: 

cp ~/.bashrc ~/.bashrc.bk
echo "# Powerline" >> ~/.bashrc
echo "export PATH=$PATH:$HOME/Library/Python/2.7/bin" >> ~/.bashrc
echo "powerline-daemon -q" >> ~/.bashrc
echo "POWERLINE_BASH_CONTINUATION=1" >>  ~/.bashrc
echo "POWERLINE_BASH_SELECT=1" >> ~/.bashrc
echo ". /usr/share/powerline/bash/powerline.sh" >> ~/.bashrc
echo "Done! :)"

Check your Python version BTW 

python -V

Now you want to add to the powerline the git theme on Shell, this is very easy! I added in the repo my config file for this (very standard BTW). 

cp /usr/share/powerline/config_files/config.json ./config.json.bk
cp ./powerline-conf/config.json /usr/share/powerline/config_files/

You will need to open a new terminal after changing the config.json file.

More info: https://devpro.media/install-powerline-ubuntu/#edit-your-powerline-configuration

4.2 Some fun

I love the pokemon say addon for terminal, is a litle bit of fun on your term:

  • https://github.com/possatti/pokemonsay
sudo apt-get install fortune cowsay

For Fedora, there is an slight difference 

sudo dnf install fortune-mod

Some test that you have preinstalled what is needed: 

fortune | cowsay


cd ~/
git clone http://github.com/possatti/pokemonsay
cd pokemonsay
./install.sh

Now you want to add it to your .bashrc file to get some cool wellcome everytime you enter to your terminal. 

cp ~/.bashrc ~/.bashrc.before.pokesay
echo "# Pokemon say add-on"
echo "fortune | ~/bin/pokemonsay " >> ~/.bashrc
diff ~/.bashrc ~/.bashrc.before.pokesay

5.3.1 reveal-js for Spaceemacs configuration

A part from LibreOffice suite you may want to have a powerfull tool for presentation. This is for sure reveal.js, you can include it in your org configuration adding in your user layer dotspacemacs-configuration-layers inside dotspacemacs/layers the following 

     org
     (org :variables
          org-enable-github-support t
          org-enable-reveal-js-support t)

This configuration is included in the .spacemacs file.
